=============================================================
  Likhi (লিখি) — Intelligent Bangla Typing System for Windows
  Version 1.0.0 Release Candidate
=============================================================

Mission:
  Build the most reliable, intelligent, natural, and user-friendly
  Bangla phonetic typing experience for Windows.

Features:
  - Natural Phonetic / Banglish typing (ami -> আমি, bhalo -> ভালো)
  - Full Unicode 15.0 compliance & perfect complex conjunct rendering
  - Grapheme-aware Backspace (zero dangling viramas)
  - Candidate Selection via 1-6 keys (top-row & numpad)
  - Adaptive Personal Learning (learns writing style over time)
  - 100% Offline operation (zero network dependencies)
  - Native Windows Keyboard Coexistence (shortcuts & navigation keys never hijacked)
  - Seamless Microsoft Office integration (Word, Excel, PowerPoint)
  - Safe atomic dictionary persistence (zero corruption on sudden shutdown)

Usage:
  1. Press [Win + Space] to select 'Likhi (লিখি)'.
  2. Start typing in Microsoft Word, Excel, PowerPoint, Notepad, Chrome, or any Windows app.
  3. Type Romanized Bengali phonetically.
  4. Use Space or candidate numbers (1-6) to commit.
  5. Configure settings via the 'Likhi Settings' Start Menu shortcut.
